# nl80211模块与cfg80211模块交互

[toc]

`nl80211_small_ops` 不是独立模块，它就是 `cfg80211` 模块里的 `nl80211` 命令分发表。用户态发来的 `generic netlink` 命令，先在这张表里找到回调，再进入 `cfg80211` 的 `wiphy` / `rdev`，最后落到驱动的 `cfg80211_ops`

## 注册路径

`cfg80211` 的模块初始化会把这张表交给 `generic netlink`

1. `fs_initcall(cfg80211_init)` 进入 `cfg80211_init()`
2. 其中调用 `nl80211_init()`
3. `nl80211_init()` 执行 `genl_register_family(&nl80211_fam)`

`family` 定义把表挂上去：

```C
// linux-7.3\net\wireless\nl80211.c
static const struct genl_small_ops nl80211_small_ops[] = {
	{
		.cmd = NL80211_CMD_SET_WIPHY,
		.validate = GENL_DONT_VALIDATE_STRICT | GENL_DONT_VALIDATE_DUMP,
		.doit = nl80211_set_wiphy,
		.flags = GENL_UNS_ADMIN_PERM,
	},
	// ......
}
```
